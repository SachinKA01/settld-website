Questions

Asked by CAs, answered plainly.

Do I need to change how I use Tally?

No. You import one file through Tally's own Import menu.

Does SETTLD file returns?

Not yet. It prepares GSTR-1 and GSTR-3B drafts. You file on the GST portal.

What bills can it read?

Phone photos, scans and PDFs. E-invoice QR codes are checked too.

Do clients need to install anything?

No. They open a link on their phone.

Who can see my data?

Only your firm. Each client sees only their own bills.

What does it cost later?
